## How this folder is organised

Files are **rank-prefixed**: `01` has the smallest q. Sorting by filename sorts by
significance, and the same number is the same gene in both folders.

```
significant_genes.tsv   one row per gene, ranked — start here
haplotype_groups.tsv    per-haplotype-group n / mean / median / SD, these genes only
CombinedPDF/            crosshap tree + phenotype violin, one PDF per gene
Heatmaps/               haplotype and genotype heatmaps, one PDF per gene
```

Filename pattern: `NN__trait__gene__qVALUE.pdf`, so `ls CombinedPDF/*fiber*`
gives that trait's figures in rank order.

## Reading these numbers

**`eta_squared`** = (H − k + 1)/(n − k): the share of phenotype rank variance explained
by haplotype group. **`delta_top_bottom_sd`** = highest-mean group minus lowest-mean
group, in phenotype SD. These matter more than q here: every gene in this list sits at
a locus that was *selected* for association with this trait, so a small p-value is close
to guaranteed — the effect size is what carries information.

**Count loci, not just genes.** These 23 genes sit in **12 loci**; genes
within a locus are in LD and are not independent discoveries. Per-locus counts are in
`../Stats/locus_summary.tsv`.

Most gene-dense loci here: `fiber_L08` (7 genes), `starch_L04` (2 genes), `starch_L03` (2 genes).
