# Flowering time: settled (2026-09-16)

**Write it as "days from sowing to heading" and say nothing about GDD.** This study uses the
`flowering_time` column (medians 110 / 104 / 103 days in 2019 / 2020 / 2021) for the BLUPs, H² and
correlations. No conversion and no analysis change is needed.

Background, so it is not re-derived: the same measured trait appears in Potapenko et al. 2026 *Mol Ecol*
(their reported 73-day minimum and 74-day spread match this project's 2020 season exactly), so cite that paper
for the common garden only. GDD is irrelevant here: `Z11_GDD` holds a growing-degree-day version of the same
records and is unused, the thesis converted flowering time to GDD, and Evgeny's papers use GDD only for
intervals between stages. Whether his own H² and GWAS ran on days or GDD is not stated in his paper, so claim
the shared trait and experiment, never a shared analysis scale.
